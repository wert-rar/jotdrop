# Скрытие заметок по тегам в JotDrop

## Принятое поведение — 2026-10-13

Реализовано в Obsidian-плагине на ветке `codex/tag-visibility`, база `c634354dfaa51bf07cd4c38f57532cb67888cce7`. Сборка установлена в Obsidian 2026-10-13 из коммита `4210a4c3243c57ce013f842a004a0d27badaa611`; ожидается перезапуск приложения для загрузки нового JavaScript. Android не изменён.

- По умолчанию все теги включены. Клик выключает тег, перечёркивает его и скрывает заметки с ним. Повторный клик возвращает видимость.
- Кнопки глаза перед тегами: Show all / Hide all. Пользователь явно выбрал, что Hide all скрывает вообще все заметки, включая заметки без тегов.
- Переключатель Untagged управляет заметками без тегов отдельно.
- Достаточно одного выключенного тега, чтобы скрыть заметку с несколькими тегами.
- Show all сбрасывает видимость всех категорий, сохраняя текст поиска. Полный сброс пустой выдачи очищает и поиск.
- Исключения хранятся только в текущем представлении до сброса/его закрытия. Настройки и Markdown-файлы не изменяются.
- Окно остальных тегов использует ту же модель. Все исключённые теги видимы в основной панели, включая теги за пределами восьми частых.
- Hide all выключает существующие на момент нажатия теги и категорию без тегов.

## Аналоги и выбор интерфейса

- [Obsidian Search](https://obsidian.md/help/plugins/search): отрицание условий тегов через `-tag:#архив`.
- [Bear](https://bear.app/faq/how-to-search-notes-in-bear/): исключение тега через `-#tag`.
- [Tag Wrangler](https://github.com/pjeby/tag-wrangler): включение и исключение тега через контекстное меню.
- [Amplenote](https://assets.amplenote.com/help/search_filter_tags_groups): сочетание включения и исключения, например `in: work,^daily-jots`.

Первоначальная рекомендация сохраняла положительный фильтр по клику. Пользователь выбрал более прямое управление видимостью в существующей строке тегов: включено по умолчанию, клик скрывает. Именно этот выбор реализован.

## Основные файлы

- src/view.ts: excludedTags, hideUntagged, панель, общий предикат и сброс.
- src/tagPicker.ts: доступные с клавиатуры кнопки, общий набор исключений, восстановление фокуса в окне тегов.
- src/i18n.ts: подписи в существующих английском и нидерландском словарях.
- styles.css: глаза, перечёркивание и приглушение.
- scripts/check-fork-browser.cjs: интеграционные проверки и снимок панели.
