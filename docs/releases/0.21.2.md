# JotDrop 0.28.24

This combined release includes the Obsidian fork plugin **0.21.2** and the original, unchanged upstream Android **0.28.24** APK.

## Obsidian plugin

- Recurring reminders in the compact bell panel; labels in compact pickers and board filters.
- Import from Google Keep, Markdown exports (including Apple Notes exports) and Evernote ENEX, with attachments.
- Typed hashtags stay real Obsidian tags and participate in search and visibility filters.
- Archive and restore preserve notes with colliding filenames; link previews and mobile keyboard layout are improved.
- Preserves the fork's Markdown cards, native Live Preview, saved columns, cached filtering and fast drag-and-drop without waiting for previous file saves.

Install main.js, manifest.json and styles.css into the existing jotdrop plugin folder and reload Obsidian. The plugin ID remains jotdrop. The plugin release tag is 0.21.2, matching its manifest.

## Android

The attached jotdrop.apk is copied byte-for-byte from [Diexar-Labs JotDrop Android 0.28.24](https://github.com/Diexar-Labs/jotdrop/releases/tag/v0.28.24). No Android interface, behavior, signing key, versionCode or updater changes were made. It includes upstream's interrupted-save recovery, recurring reminders, labels, hashtag fixes and cleaner card text.

Use the APK to update an existing GitHub-distribution install. Google Play uses a separate signing channel. Manual card ordering differs: the fork plugin stores jotdrop_order and local columns; upstream Android stores order. This release does not migrate those fields.

BUILD-INFO.txt identifies the fork build; ANDROID-BUILD-INFO.txt is the original upstream build record. The workflow checks the APK against the upstream SHA256 and verifies its package, version and signature before publication.
