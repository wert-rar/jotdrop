# JotDrop fork

A fork of [JotDrop by Diexar Labs](https://github.com/Diexar-Labs/jotdrop), based on version 0.20.4. It improves note cards in Obsidian with richer Markdown rendering, Live Preview editing, and persistent manual placement.

## What changed

- **Markdown cards:** preserve paragraphs, nested lists, links, code, and embeds.
- **Live Preview editor:** Save or Archive saves your changes; Cancel discards the draft.
- **Compact controls:** icon buttons, inline tags, and a reminder popup.
- **Card placement:** a compact initial layout, with dragged cards staying in the chosen column and position. Positions are restored when the view is reopened.
- **Updates without rebuilding the grid:** dragging preserves scroll position, and checkboxes update in place.

See the [original README](https://github.com/Diexar-Labs/jotdrop/blob/main/README.md) for the upstream project, Android app, and browser extension.
