## Key technical decisions
- CLI не требуется для доставки исправления: по указанию пользователя использован регрессионный сценарий с фактическим установленным bundle. Живое профилирование остаётся недоступным; результаты стенда не доказывают устранение всех лагов Obsidian.
- Асинхронные запросы чтения разделяются только для одинаковой cardsVersion; новый запрос/закрытие отменяет применение устаревшего результата. Сохранение ручных колонок, тегов и режима сортировки не изменено.
- Ветка `codex/tag-visibility`, база `origin/main` `c634354dfaa51bf07cd4c38f57532cb67888cce7`; Android не изменён.
- Исходники установленного исправления: commit `0a943ac7f29c77e5f1fae221342f9b94783e2ba1`; документирующий коммит после установки не меняет bundle. Origin/main остался c634354dfaa51bf07cd4c38f57532cb67888cce7.
- Любой исключённый тег скрывает заметку. Фильтры временные, в пределах view.
- Повторное использование снимка требует совпадения cardsVersion; сохранение колонок — также прежнего количества колонок.
- Отсоединённые карточки сохраняются до обновления данных/закрытия; повторно создавать Markdown при возврате тега не требуется.
- Canonical AgentMemory scope: `wert-rar/jotdrop`. MCP недоступен; recall/save не выполнены.
- Сортировка использует существующие sortMode и временные метки; переключение не меняет jotdrop_order или cardLayout. Меню предлагает три согласованных режима; дополнительные режимы в настройках сохранены и корректно отображаются на кнопке. Подробности: [режимы сортировки](docs/sort-modes.md).
- Проверка upstream 2026-10-16: `upstream/main` `903fe57bb064a1daaec4250b4ac400519e4e75dd`, плагин 0.20.13, Android 0.28.13 (67), 27 коммитов после общей базы 0.20.4. [Исследование и рекомендуемый порядок](docs/upstream-update-assessment.md): после проверки текущей функции слить её в свой main, затем интегрировать upstream в отдельной ветке. Это рекомендация, слияние ещё не запрошено и не выполнено.
